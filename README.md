## Prerequisites

- **macOS:** 14.0+ (Sonoma) or 15.0+ (Sequoia) running on Apple Silicon / Intel
- **Python:** 3.12+ (installed via Homebrew or standard macOS installer)
- **Database:** PostgreSQL 16+ running locally (`brew install postgresql@16`)
- **Database Instance:** `my_tarot_db` configured and populated with `thoth_cards` schema
