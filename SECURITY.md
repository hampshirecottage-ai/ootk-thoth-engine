# Security Policy

## Reporting a vulnerability

Please report security problems privately through GitHub's
[private vulnerability reporting](https://github.com/hampshirecottage-ai/ootk-thoth-engine/security/advisories/new)
rather than opening a public issue.

Include what you found, how to reproduce it, and which commit or version you tested.
You should get a reply within a week.

## Supported versions

Only the latest commit on `main` is supported.

## Scope

This repository holds the engine, card tables, web app and tests. Readings, reports,
logs, personal seeds, database dumps and credentials are never committed; if you find
any of those in the repository or its history, please report it the same way.
