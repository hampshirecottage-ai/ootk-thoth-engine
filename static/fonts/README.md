# Fonts

Used by the start page banner (templates/index.html). Each file is the Latin subset of the
variable font as served by Google Fonts, saved here because the site's Content-Security-Policy
only allows fonts from its own origin (`font-src 'self'`).

| --- | --- | --- |
| `cinzel-latin.woff2` | Cinzel (headline) | SIL Open Font License 1.1, `OFL-cinzel.txt` |
| `inter-latin.woff2` | Inter (body text) | SIL Open Font License 1.1, `OFL-inter.txt` |
| `jetbrains-mono-latin.woff2` | JetBrains Mono (labels) | SIL Open Font License 1.1, `OFL-jetbrainsmono.txt` |
